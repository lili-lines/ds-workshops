# Mission Exoplanète, énigme CE1

[[slides]]

Une énigme de 30 minutes pour un cours particulier, avec un ou une élève de CE1 francophone, sur le thème de l'espace et des exoplanètes. Le robot Zip est en panne : chaque énigme résolue donne une lettre, et les 6 lettres forment le mot de passe du vaisseau.

Compétences travaillées : lecture, observation d'image, repérage sur un quadrillage, oral, écriture, raisonnement.

## Déroulé (30 min)

| Temps | Étape | Compétence |
|---|---|---|
| 3 min | Message de Zip | entrée dans l'histoire |
| 4 min | Énigme 1 | lecture et compréhension |
| 4 min | Énigme 2 | observation d'une image |
| 5 min | Énigme 3 | repérage sur un quadrillage (carte) |
| 4 min | Énigme 4 | oral : devinettes |
| 6 min | Énigme 5 | écriture : mots mélangés et une phrase |
| 3 min | Énigme 6 | raisonnement à partir d'une image |
| 1 min | Mot de passe et fin | |

## Corrigé

1. Lecture : B, autour d'une autre étoile → É
2. Image : B, Saturne → T. Bonus : 8 planètes
3. Carte : A1, 3 cases à droite (D1), 2 cases en bas (D3) → planète O. Bonus : la comète est en B5
4. Oral : la Lune, une étoile, une fusée → donner la lettre I
5. Écrit : LUNE, MARS, SOLEIL → première lettre du premier mot : L
6. Zone habitable : planète 2 → E

Mot de passe : ÉTOILE
