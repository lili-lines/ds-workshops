# Percy Jackson : le taxi magique, FLE A1

[[slides]]

Une énigme de 2 heures pour des apprenants de français langue étrangère, niveau A1, autour d'un extrait de Percy Jackson. Percy doit appeler un taxi magique : chaque activité donne une lettre, et les 7 lettres forment le mot de passe.

Compétences travaillées : écoute, lecture, grammaire, description d'image, dessin, écriture, vocabulaire.

## Déroulé (2 h)

| Temps | Étape | Compétence |
|---|---|---|
| 10 min | La mission, les personnages | entrée dans l'histoire |
| 20 min | Activité 1 : le professeur lit l'extrait original, deux fois | écoute |
| 15 min | Activité 2 : texte simplifié | lecture |
| 15 min | Activité 3 : mon / ma | grammaire |
| 15 min | Activité 4 : décrire Tyson | image, description (être / avoir) |
| 15 min | Activité 5 : dessiner le taxi | écoute et dessin |
| 15 min | Activité 6 : se présenter comme un demi-dieu | écriture |
| 10 min | Activité 7 : les dieux et leur domaine | vocabulaire |
| 5 min | Mot de passe et fin | |

## Corrigé

1. Écoute : noms entendus : Annabeth, Tyson, Athéna, Poséidon (pas Hermès, ni Zeus). Vrai, vrai, faux (« il n'est pas sourd ») → lettre T
2. Lecture : A, Athéna → R
3. Grammaire : 1. mon, 2. mon (devant une voyelle : mon amie), 3. mon, 4. ma → B, mon → I
4. Image : grand, cheveux bruns, content ; B, un œil → D
5. Dessin : un taxi gris et vieux, trois vieilles dames, un seul œil → lettre E
6. Écriture : trois phrases correctes avec mon / ma → lettre N
7. Les dieux : Zeus, le ciel ; Poséidon, la mer ; Athéna, l'intelligence ; Arès, la guerre → A, la mer → T

Mot de passe : TRIDENT, l'arme de Poséidon.

Point de grammaire de la phrase 2 : « amie » est féminin mais commence par une voyelle, donc on dit « mon amie ». C'est un bon piège à discuter.
